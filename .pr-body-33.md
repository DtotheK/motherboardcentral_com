## What this is

A guide to enabling firmware TPM and Secure Boot, covering the Windows 11
eligibility path and the anti-cheat path, in an order that does not leave the
reader with an unbootable machine.

## Sourcing, and where the page is deliberately narrower than the issue

The issue's acceptance criteria require each BIOS menu path to be cited to that
vendor's own support page, and say that where a path cannot be confirmed at the
vendor source we describe the setting name instead of inventing a path. That
fallback did most of the work here.

For every brand other than ASUS the page names the setting to look for — fTPM /

closing note on the page states that rule explicitly, so it does not read as an
oversight.

## Two accuracy decisions worth a second pair of eyes

- **No CVSS score for the fTPM CVEs.** AMD scores them 8.5 and 8.3 on CVSS 4.0
  (as quoted in the #20 advisory copy); NVD carries CISA-ADP CVSS 3.1 figures of
  7.9 and 5.9. Rather than pick a side on a guide page, the section describes
  what the flaws are, says both need local privileged access, and links NVD. A
  test asserts no CVSS figure appears.
- **No AGESA version string**, same rule as #20 and #32.

Nothing on the page contradicts the #20 advisory copy on PR #76: both say the
fix ships as a motherboard BIOS update, that Windows Update will not deliver it,
and that the BitLocker recovery key comes first.
