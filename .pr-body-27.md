Every value published here was read out of GIGABYTE's page for this exact SKU via search-engine extraction, and each one is corroborated by at least one independent outlet that names the same model:

| Hybrid 6+2+1 phase VRM | GIGABYTE product page; Overclocking.com. Explicitly **not** the 8+1+1 of the GAMING X |
| 4 x SATA 6 Gb/s, 2.5GbE, Wi-Fi 6E, 8-channel HD audio | GIGABYTE product page |
| Up to 64GB | GIGABYTE's 2-DIMM boards list 32GB single-DIMM capacity; 2 x 32GB = 64GB. Matches the issue's table |

Sibling-model contamination is the real risk on this board, and searches did repeatedly return the **GAMING X** spec sheet (4 DIMMs / 128GB, 8+1+1, AX210, Bluetooth 5.3, its rear I/O layout). **None of that is on this page.** A test fails the build if the page ever adopts the GAMING X phase count or links its spec page.

Per CLAUDE.md rule 1, anything I could not attribute to this exact SKU was left off the page rather than guessed, and the page says so in a "What we have not verified" section: the rear panel layout and video outputs, the audio codec, the Bluetooth version, the memory speed list, and a price.

**No Amazon link.** No ASIN could be confirmed as unambiguously this model rather than one of its four near-identically-named siblings, so the page ships without one (rule 3).
