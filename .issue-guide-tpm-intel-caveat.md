## What

`guide-tpm-secure-boot.html` walks readers through **turning firmware TPM on**,
with a section for each vendor:

- line 159 — `<h2 id="enable-amd">Enabling Firmware TPM: AMD Boards (fTPM)</h2>`
- line 170 — `<h2 id="enable-intel">Enabling Firmware TPM: Intel Boards (PTT)</h2>`

It then carries a firmware caveat that is **scoped to AMD only**:

- line 96 (contents) — `<a href="#ftpm-caveat">The AMD fTPM Caveat</a>`
- line 244 — `<h2 id="ftpm-caveat">AMD fTPM: The Firmware Caveat Worth Knowing First</h2>`
- line 248 — "...**AMD** ships that reference code as fTPM, which is how a
  specification-level bug becomes a motherboard update."

The caveat is accurate and well sourced. The problem is the scoping. CVE-2026-6726
and CVE-2026-6727 are **not AMD bugs** — the page already says so correctly
("Two vulnerabilities in the Trusted Computing Group's TPM 2.0 reference code").
They are TCG reference-code bugs, and **CERT/CC lists Intel as Affected
alongside AMD**:

> VU#431093, published 11 August 2026, updated 12 August 2026.
> **Affected: AMD, Intel.** Not Affected: Absolute Software, Ampere Computing,
> libtpms (IBM sponsored), Meta.

Intel has its own advisories for the same two CVEs — **INTEL-SA-01372**
(CVE-2026-6726) and **INTEL-SA-01371** (CVE-2026-6727) — covering Intel CSME and
Intel SPS firmware. Intel ships the affected reference code as **PTT**, which is
exactly the feature this page tells Intel readers to switch on.

So an Intel reader follows our instructions, enables PTT, and leaves the page
believing the firmware caveat was somebody else's problem.

## Why

Reader protection, and it is the same argument the AMD caveat already makes. The
whole point of that section is: *a firmware TPM is firmware, so when a flaw is
found the fix arrives as a motherboard BIOS update, and Windows Update will not
deliver it.* That sentence is exactly as true for Intel PTT as for AMD fTPM. Our
page currently makes it only for AMD, which reads as an implicit
"Intel is fine" — an accuracy problem, not just an omission.
