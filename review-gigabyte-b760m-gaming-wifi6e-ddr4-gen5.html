Overview

The B760M GAMING WIFI6E DDR4 GEN5 is a Micro-ATX board for Socket LGA 1700 built on Intel's B760 chipset. It is a 2026 refresh of an older B760M design, and the reason it exists is the combination in its name: DDR4 memory and a PCIe 5.0 x16 graphics slot on the same board.

That combination is unusual. Most LGA 1700 boards offering a Gen5 graphics slot also require DDR5. With DDR5 kits still expensive, a board that takes the DDR4 sticks you already own while leaving the graphics slot ready for a Gen5 card is a specific answer to a specific problem.

The compromises are equally specific, and both are covered below: the memory layout is two slots rather than the four this segment usually offers, and PCIe 5.0 stops at the graphics slot.

What the Gen5 slot covers

This is the single most important thing to understand about this board, and the easiest thing to get wrong when a product name ends in GEN5.

  • The x16 graphics slot is PCIe 5.0. GIGABYTE reinforces it and fits a quick-release latch. This is where the Gen5 link lives, and it is the reason the board carries the GEN5 name.
  • Both M.2 sockets are PCIe 4.0 x4. They are not Gen5 sockets. A drive rated for Gen5 speeds will still work in either one, but it will run at PCIe 4.0 rates, which is roughly half its rated sequential throughput.
  • The second expansion slot is PCIe 3.0 x1, for a capture card, a sound card or a network card.

Alongside the M.2 sockets there are four SATA 6 Gb/s ports, the usual count for a Micro-ATX board of this size.

If your priority is the fastest storage on the market rather than the fastest graphics link, this is the wrong board. Based on published specifications, its Gen5 lanes go to the graphics slot and nowhere else.

Memory: two slots, not four

The board has two DDR4 DIMM slots and supports up to 64GB in dual channel, with XMP profiles for kits that carry them. Do not assume the memory layout our other B760M reviews describe: many Micro-ATX B760 boards fit four memory slots, and this one does not.

In practice that matters in two ways. A 2 x 32GB kit fills the board and 64GB is the ceiling, so there is no headroom later. And with only two slots there is no cheap upgrade path from a 2 x 8GB kit; you replace what is in there rather than adding to it. Buy the capacity you want up front.

The upside of a two-slot layout is that it is the easier configuration for a memory controller to drive, which is part of why dual-slot boards often hold higher speeds. We have not tested that on this board and are not claiming it.

VRM & Power Delivery

GIGABYTE lists a hybrid 6+2+1-phase design. That is mid-range power delivery for the B760 tier, and it is a step behind the 8-phase-plus arrangements on the pricier boards in GIGABYTE's own B760M range.

Based on published specifications, it is sized for the 65 W and mid-range 13th and 14th Gen parts most B760 buyers pair with a board like this. B760 does not permit CPU overclocking anyway, so the phase count matters mainly for sustained all-core loads on a higher-TDP chip. If that describes your build, look at a heavier VRM.

Connectivity & I/O

Wired networking is 2.5 Gigabit Ethernet. Wireless is Wi-Fi 6E with Bluetooth, added alongside the wired port rather than in place of it, so you can run both.

Wi-Fi 6E adds the 6 GHz band to what Wi-Fi 6 already offered. That band is short-range but far less congested than the older ones, which is the practical benefit in a block of flats or an office. It needs a router that supports it.

Audio is 8-channel HD audio. GIGABYTE's marketing copy for this board describes the audio capacitors rather than the codec, and we could not verify a codec model number for this exact SKU, so the specification table above says so instead of naming one.

Pros & Cons

Pros

  • A PCIe 5.0 x16 graphics slot on a DDR4 board, which is a rare pairing
  • Reuses DDR4 memory you may already own
  • Two M.2 sockets at PCIe 4.0 x4, plus four SATA ports
  • 2.5 Gigabit Ethernet and Wi-Fi 6E together, not one instead of the other

Cons

  • Two memory slots and a 64GB ceiling, where most of this class gives you more
  • The Gen5 link is the graphics slot only; both M.2 sockets are PCIe 4.0
  • 6+2+1 phases is mid-pack for the tier
  • DDR4 is the end of a road, not the start of one
  • The name is one word away from several different boards, which makes it easy to buy the wrong one

Who Should Buy This Board?

Someone building on LGA 1700 who already owns a DDR4 kit and wants the graphics slot to be the part that is not obsolete in three years. That is a narrow group, but it is a real one, and almost nothing else on the market serves it.

It is the wrong board if you want a Gen5 boot drive, if you want more than 64GB of memory, or if you are buying a whole platform from scratch, in which case a current socket with DDR5 is the better starting point. Whether it is good value depends on a price we cannot confirm.

Build Tips & Recommendations

  • Check the model name on the box against the one on this page, character for character. GAMING is not GAMING X, and the DDR4 and WIFI6E parts of the name both change the board you get.
  • Buy the memory capacity you want in one two-stick kit. With two slots there is no adding to it later.
  • Either M.2 socket is fine for a boot drive; both run at PCIe 4.0 x4. Pick a PCIe 4.0 drive and save the premium a Gen5 model asks for.
  • Check GIGABYTE's CPU support list for your exact processor before buying, and its memory QVL for your exact kit.
  • Micro-ATX fits both Micro-ATX and ATX cases. In a smaller case, check graphics card length clearance first.
  • Update to the latest BIOS before you install components.
