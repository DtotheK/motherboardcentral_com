Add 'Show differences only' toggle to the compare table

Comparing two boards from the same chipset family leaves most of the 17
spec rows identical, so the rows that actually decide the purchase are
buried. A checkbox above the table now collapses every row where all
currently selected boards render the same value.

- Toggle is built in JS and inserted above #compare-table-wrap, so
  compare.html needs no markup change.
- Default off; the checked state lives in the compare closure so it
  survives the re-render on every selection change and re-evaluates
  against the new selection.
- Hidden and disabled below two selected boards - nothing can differ.
- Empty slots are excluded from the comparison, so an unfilled third
  slot's '--' does not keep an otherwise identical row on screen.
- If every row matches, an honest message replaces the table instead of
  rendering an empty one.
- Winner highlighting is untouched and works in both states.

Adds scripts/compare-diff-toggle.test.mjs, which runs the real js/main.js
in a vm against a DOM stub - no framework or build tooling added.
