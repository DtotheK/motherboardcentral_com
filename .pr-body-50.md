| `review-asus-tuf-gaming-x870-plus-wifi.html` | 3x M.2 | `Four M.2 Slots` |
| `review-gigabyte-x870-aorus-elite-wifi7.html` | 3x M.2 | `4X M.2` |
| `review-msi-pro-x870-p-wifi.html` | 3x M.2 | `3X M.2` — agrees |
| `review-msi-mag-x870-tomahawk-wifi.html` | 3x M.2 | listing does not state a count |

This does not affect the four verification tests, which cover socket, chipset and memory generation — those agree for all five boards, so the ASINs are sound. But the issue says to leave spec tables alone, and CLAUDE.md says to flag rather than guess, so nothing was edited. **A human should verify the M.2 counts against the manufacturer spec pages and correct them in a separate issue.**
