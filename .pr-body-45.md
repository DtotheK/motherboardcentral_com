Every board in this batch disagrees with our own spec table on at least one value **outside** the comparison set. None of them casts doubt on board identity (name, socket, chipset, memory generation, form factor and WiFi all match), so the ASINs were used. **No spec table was edited** — issue #45 forbids it — but per CLAUDE.md rule 1 these are flagged rather than guessed:

| MSI MPG Z890 Carbon WiFi | LAN | `2.5G` | secondary | dual LAN: 5G Killer E5000B + 2.5G Intel I226V |
| MSI MPG Z890 Edge TI WiFi | M.2 slots / LAN | `4x M.2` / `2.5G` | secondary | 5x M.2 / 5G Killer E5000B |
| MSI PRO Z890-A WiFi | M.2 slots / LAN / SATA | `3x M.2` / `2.5G` / `6` | secondary | 4x M.2 / 5G Realtek / 4x SATA |

The two ASUS rows are **confirmed against ASUS's own techspec pages** — our tables are wrong there. The three MSI rows are **not settled**: MSI's spec pages return HTTP 403, so those figures come from retailer and reviewer sources, not the manufacturer, and need a human check before any table is edited.

This is why recipe step 12's "zero spec discrepancies" condition is not met, so: `needs-human`, no auto-merge.
