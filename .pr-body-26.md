## Spec verification

`gigabyte.com` returns HTTP 403 to automated fetches, so the spec pages could not be
retrieved directly. Every value below was taken from GIGABYTE's own published
specification text as indexed from those pages, then corroborated against two
independent outlets (Igor's Lab and ThinkComputers). Nothing rests on a single
secondary source.

| Field | Value | Source |
|---|---|---|
| Socket / chipset / form factor | AM4 / B450 / Micro-ATX | GIGABYTE + both outlets |
| CPU support | Ryzen 5000 / 4000 / 3000 | GIGABYTE ("Socket AM4 supporting AMD Ryzen 5000 / 4000 / 3000 Series Processors") |
| VRM | 4+2-phase digital | GIGABYTE ("Digital 4+2 phases VRM solution") |
| Memory | 4 × DDR4 DIMM, up to 128GB | GIGABYTE + both outlets |
| M.2 | `M2A_CPU` PCIe 3.0 x4 (CPU) + `M2B_SB` PCIe 2.0 x2 (chipset) | GIGABYTE storage spec text |
| SATA | 4 × SATA 6 Gb/s | GIGABYTE |
| Rear I/O | 1 × DisplayPort, 2 × HDMI, 4 × USB 3.2 Gen 1, 3 × USB 2.0/1.1 | GIGABYTE back-panel spec, confirmed separately for **both** models |
| LAN | Realtek Gigabit Ethernet | GIGABYTE ("GbE LAN", and an RJ-45 in the WIFI6E back-panel list) |
| Wireless (WIFI6E only) | Realtek RTL8852CE, Wi-Fi 6E 2.4/5/6 GHz, Bluetooth 5.4 | Igor's Lab, matching the issue |

Two points worth a reviewer's eye:

1. **The WIFI6E keeps its wired port.** GIGABYTE's WIFI6E back-panel list includes an
   RJ-45, and Igor's Lab states Gigabit Ethernet for both models. The wireless module is
   an addition, not a substitute. Both pages say so, and both spec tables read `LAN: 1G`.
2. **The second M.2 is PCIe 2.0 x2.** It is stated in the spec table, given its own
   "Storage: the M.2 catch" section with the bandwidth consequence spelled out, and
   listed as a con. A test asserts it appears in the prose and not only in the table, and
   a second test bans phrasings that would sell it as a second full-speed NVMe slot.

## What the pages deliberately do not say

GIGABYTE has published no price, no on-sale date, and no audio codec, so none of those
appear. Each page carries a "What GIGABYTE has not published" section listing the gaps
instead of filling them. No ASIN was confirmed for either board, so there is **no Amazon
link on either page** (CLAUDE.md rule 3). There is no star rating and no `aggregateRating`
JSON-LD: we have not tested these boards, and every analytical claim is framed as
"based on published specifications".

## Deviations from the existing review-page template

- **No product photo.** No image asset exists for either board and inventing one is not an
  option, so the `card-img` block and the hero image are omitted rather than pointing at a
  file that does not exist.
- **No rating block or video review**, for the reasons above.
- **Not added to the compare tool or site search.** Both are driven by
  `motherboardDatabase` in `js/main.js`, whose records require an `amazonSearch` value —
  `getAmazonUrl()` renders it as `https://www.amazon.com/s?k=...`, which CLAUDE.md rule 3
  forbids. Adding these boards there needs a change to that helper, which issue #26 does
  not specify, so it is left out of this PR rather than guessed at.
- **`data-price="-1"` on both review cards.** The price filter buckets on `data-price`, and
  `parseFloat(undefined) || 0` would put a priceless board in "Under $150" — a price claim
  we cannot make. A negative sentinel keeps the cards visible under "All Prices" and out of
  every bucket. There is an HTML comment at each card explaining it, and a test asserting it.
- **One line added to the reviews.html chipset filter** (`<option value="B450">`), so the new
  cards are reachable by the same filter every other chipset on the page has. No nav, footer
  or layout markup changed.
