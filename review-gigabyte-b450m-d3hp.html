Overview

The B450M D3HP is a Micro-ATX board for Socket AM4 built on AMD's B450 chipset. It is a new 2026 product on an old platform: DDR4 memory, PCIe 3.0, and a feature set aimed at people who already own an AM4 processor and a set of DDR4 sticks.

What stands out for a board at this level is the memory layout. Four DIMM slots and support for up to 128GB is more than most budget Micro-ATX boards offer. What holds it back is power delivery and the second M.2 slot, both covered below.

There is no onboard wireless on this model. If you want Wi-Fi, GIGABYTE sells the otherwise identical B450M D3HP WIFI6E.

Security advisory: check your BIOS

AMD published bulletin AMD-SB-7064 on 11 August 2026. It covers two high-severity flaws in AMD's firmware TPM: CVE-2026-6726, an information-leakage flaw that lets a forged TPM key be certified as genuine, and CVE-2026-6727, a timing side-channel. AMD scores them 8.5 and 8.3 on CVSS 4.0. Affected processors run from Ryzen 3000 to Ryzen 9000, plus Threadripper, Ryzen AI and Ryzen Embedded parts. Both attacks need local privileged access, so neither is remotely exploitable. The underlying flaw is in the Trusted Computing Group's TPM 2.0 reference code, which AMD ships as fTPM.

The fix arrives as a motherboard BIOS update. Windows Update will not install it. Check GIGABYTE's security page and this board's own support page, install the latest BIOS, then look for an fTPM or TPM security fix in the release notes. Coverage varies by board, and we have not verified that a fixed BIOS exists for this one.

Before you flash: if this machine uses BitLocker, save your recovery key first. A firmware update can trigger BitLocker recovery, and Windows will then ask for a 48-digit key before it unlocks the drive. Our BIOS update guide covers the safe order.

Storage: the M.2 catch

The board has two M.2 slots, and they are not equivalent. Read the second row of this section before you plan your storage.

  • Top slot (CPU-connected): PCIe 3.0 x4. This is the fast one. GIGABYTE also lists SATA M.2 support here.
  • Second slot (chipset-connected): PCIe 2.0 x2. Two lanes at the older signalling rate works out at roughly a quarter of the top slot's bandwidth. It is a perfectly good home for a game library, a scratch disk or a backup drive. It is not a place to put the drive you boot from if you care about sequential throughput.

Alongside those there are four SATA 6 Gb/s ports, which is the usual count for a Micro-ATX board of this size.

A modern NVMe drive in the second slot will not run at its rated speed. That is not a defect, it is the chipset: B450 simply does not have faster lanes to give.

VRM & Power Delivery

GIGABYTE lists a digital 4+2-phase design. That is entry-level power delivery, and it sets the sensible ceiling for this board. Based on published specifications, it is sized for the 65 W processors that make up most of the AM4 install base. If your plan involves a 105 W part running flat out for hours, or any serious overclocking, a heavier VRM is the safer buy.

GIGABYTE's published processor support covers the Ryzen 5000, 4000 and 3000 series, including the models with integrated graphics.

Connectivity & I/O

Wired networking is Realtek Gigabit Ethernet. There is no onboard wireless on this model at all, so budget for a PCIe card or a USB adapter if you need it.

The rear panel carries seven USB ports: four USB 3.2 Gen 1 and three USB 2.0. Video output is one DisplayPort and two HDMI, which matters because a good number of AM4 chips have integrated graphics. There is also a front-panel USB-C header rated at 5 Gb/s.

GIGABYTE has not published the audio codec model for this board, so we are not naming one. The specification table above says so rather than guessing.

What GIGABYTE has not published

This is the part most spec sheets leave out, and it is worth knowing before you plan a build around this board:

  • A price, in any region.
  • A date when the board goes on sale, or which regions it goes on sale in.
  • The audio codec.
  • A supported memory speed list. Check GIGABYTE's memory QVL before you buy a high-speed DDR4 kit for it.

Pros & Cons

Pros

  • Four DDR4 slots and 128GB support, which is generous for a budget Micro-ATX board
  • The top M.2 slot is CPU-connected at PCIe 3.0 x4
  • Two HDMI outputs plus DisplayPort suit AM4 chips with integrated graphics
  • A brand-new board for a platform whose used-board market is ageing

Cons

  • The second M.2 slot is PCIe 2.0 x2, not a second full-speed NVMe slot
  • 4+2 phases is thin for high-TDP processors or overclocking
  • Gigabit Ethernet only, where newer boards have moved on
  • No onboard wireless
  • The platform tops out at PCIe 3.0

Who Should Buy This Board?

Two groups. The first is anyone whose AM4 board has died and who does not want to replace a working processor and memory to get a running PC back. The second is a first-time builder assembling a budget machine around a used Ryzen 3000 or 5000 chip and DDR4 sticks they already have.

If you are buying a whole platform from scratch, look at current sockets first. This board makes sense because of what you already own, not on its own merits against a modern chipset. Whether it is good value depends on a price GIGABYTE has not announced.

Build Tips & Recommendations

  • Put your boot drive in the top M.2 slot. The second slot runs at PCIe 2.0 x2 and will hold back a fast NVMe drive.
  • Check GIGABYTE's CPU support list for your exact processor before buying. GIGABYTE publishes support for the Ryzen 5000, 4000 and 3000 series.
  • Check the memory QVL too. GIGABYTE has not published a supported speed list for this board, so do not assume a high-speed kit will train.
  • Micro-ATX fits both Micro-ATX and ATX cases. In a smaller case, check graphics card length clearance first.
  • Update to the latest BIOS before you install components, especially with a Ryzen 5000 processor.
